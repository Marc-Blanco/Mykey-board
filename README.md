## MyKey Board (mikey board)

I tried to make a functional and cool midi keyboard like a piano with 88 keys DIY, with cool features. It has 2 speakers and 2 rotary encoders to tingle things, I would like to improve on the project and this is kind of a Deltarune reference so maybe add easter eggs?
